About the Diff Checker

This tool computes a line-by-line diff of two text blocks using the Longest Common Subsequence (LCS) algorithm — the same foundation used by tools like git diff. Lines present in the modified text but not the original are shown in green (+), and lines removed from the original are shown in red (-).

The diff runs entirely in your browser using vanilla JavaScript. No text is transmitted to any server. Maximum input size is 2000 lines per side.
