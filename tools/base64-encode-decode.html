About Base64 Encoding

Base64 is a binary-to-text encoding scheme that represents binary data using only printable ASCII characters. It is commonly used to encode binary data (like images or files) in contexts that only support text, such as JSON payloads, data URLs, or email attachments.

This tool uses a UTF-8-safe implementation, so characters from any language encode and decode correctly. No data leaves your browser.
