About the Regex Tester

Regular expressions (regex) are patterns used to match character combinations in strings. This tool uses JavaScript's native RegExp to test your pattern in real time, highlighting all matches as you type.

Supported flags: i (ignore case), m (multiline anchors), s (dot matches newlines). The g flag is always applied to find all matches.
