About JWT Decoding

      

        JSON Web Tokens (JWTs) consist of three base64url-encoded parts: a header, a payload,
        and a signature. This tool decodes the header and payload so you can inspect claims like
        sub, exp, iat, and iss without
        needing the signing secret.
      

      

        Note: this tool only decodes — it does not verify the signature.
        Never trust JWT claims without server-side signature verification.
        Your token never leaves your browser.
